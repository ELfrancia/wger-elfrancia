# Codebase Analysis with Graphify

- **Graphify First Strategy**: Whenever analyzing, searching, or inspecting the codebase architecture, dependencies, functions, models, views, or component relationships, ALWAYS prioritize using the `graphify` tools (`call_mcp_tool` with server `graphify` — e.g. `query_graph`, `get_node`, `get_neighbors`, `god_nodes`, `graph_stats`, `shortest_path`, etc.) to gain structural insight into the code graph before making modifications.
